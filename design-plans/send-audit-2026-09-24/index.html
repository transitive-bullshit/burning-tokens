SEND-01 · P2 · 390 px mobile

Start with the invitation, not a wall of instructions

The long how-it-works section pushed setup far down the page. A short overview now leads directly into step 1, with agent-tool requirements in a supporting disclosure.

Affects: /send · setup

Implementation: app/send/page.tsx + components/retreat/invitation.tsx · Full before capture · Full after capture

SEND-02 · P2 · 390 px mobile

Make copying a clear handoff

The prompt appeared below old instructions, Copy competed with Watch, and Copied disappeared after three seconds. The new heading receives focus, Copy prompt leads the section, the field has a visible label, and persistent confirmation explicitly asks the human to paste and send. The current invitation no longer duplicates itself in recent visits.

Affects: /send · generated prompt and copied state

Implementation: components/retreat/invitation.tsx · Full before capture · Full after capture

SEND-03 · P2 · 390 px mobile

Explain what waiting means

The old connection message did not clearly distinguish a copied prompt from an agent opening it. A dedicated arrival section says what is being observed, asks the human to return to this tab, and explains automatic navigation. Troubleshooting and the optional visit-page link are secondary.

Affects: /send · waiting for arrival

Implementation: components/retreat/invitation.tsx · Full before capture · Full after capture

SEND-04 · P2 · 390 px mobile

Make blocked clipboard access recoverable

Copy errors appeared as a generic gate alert and left manual selection to the human. The new message is beside the prompt, the whole prompt receives focus and selection, and a successful copy retry clears the error. Copy failure does not discard or recreate the invitation.

Affects: /send · clipboard denied or unavailable

Implementation: components/retreat/invitation.tsx · Full before capture · Full after capture
